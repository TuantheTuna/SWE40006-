10 marks individual Task

Task 1.1 Pass (if completed fully with the highest quality)

Follow the WiX walkthrough and deploy a sample desktop

Task 1.3 Distinction (if completed fully with the highest quality)

Task 1.4 High Distinction (if completed fully with the highest quality)
